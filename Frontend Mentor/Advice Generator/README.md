### Built with

### What I learned

Adding logic to react is quite different coming from an Angular experience, but I find React a bit easier or even refreshing at the moment. Also, I still need to learn more about TailwindCSS

### Continued development

This challege helped me learn using logic or state management using React. Made me even think the difference Angular has on React. I am leaning into React in terms of the learning curve.
